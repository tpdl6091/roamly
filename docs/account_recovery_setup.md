# 아이디·비밀번호 찾기 설정 (직접 하는 부분)

로그인 창의 **아이디 찾기 / 비밀번호 찾기** 화면과 서버 확인 함수는 만들어 두었어요. 실제로 메일이 가려면 아래 2가지를 직접 해야 해요.

## 동작 방식
- **비밀번호 찾기**: 아이디 + 이메일 입력 → 서버가 같은 계정인지 확인(`check_account_pair`) → 맞으면 재설정 메일 발송 → 메일의 링크를 누르면 사이트로 돌아와 **새로운 비밀번호 / 비밀번호 확인** 창이 열려요 → 두 칸이 같고 6자 이상이면 변경 완료.
- **아이디 찾기**: 이메일 입력 → 그 주소로 아이디가 담긴 메일 발송.
  - 사이트는 실명을 받지 않아서 '이름' 칸은 두지 않았어요. 아이디는 **그 이메일의 주인에게만** 보내니, 이름을 더 받아도 보안은 늘지 않아요.
- 입력이 맞든 틀리든 **같은 안내 문구**를 보여 줘서, 남이 "이 이메일이 가입돼 있나?"를 알아낼 수 없어요. 같은 접속 주소에서 1시간에 20번까지만 확인할 수 있어요.
- Google로만 가입한 계정은 비밀번호가 없어서 Google 로그인을 쓰면 돼요.

## 1. SQL 실행 (1분)
Supabase → **SQL Editor** → `docs/supabase_migration_008_account_recovery.sql` 내용을 붙여 넣고 **Run**. (여러 번 실행해도 안전해요. 003 이후여야 해요.)

## 2. 재설정 메일 문구 바꾸기 (아이디가 메일에 들어가게)
Supabase → **Authentication → Emails(Email Templates) → Reset Password** 의 제목·본문을 아래로 바꾸고 **Save**.

제목: `[Roamly] 아이디 / 비밀번호 재설정 안내`

본문(HTML):
```html
<h2>Roamly 계정 안내</h2>
<p>회원님의 아이디: <strong>{{ .Data.name }}</strong></p>
<p>비밀번호를 다시 정하려면 아래 링크를 눌러 주세요.</p>
<p><a href="{{ .ConfirmationURL }}">새 비밀번호 정하기</a></p>
<p>요청하지 않으셨다면 이 메일은 무시하셔도 돼요.</p>
```
- `{{ .Data.name }}` 는 가입할 때 입력한 아이디예요. (Google로 가입해 닉네임이 없으면 비어 있을 수 있어요.)
- 아이디 찾기와 비밀번호 찾기가 **같은 메일 템플릿**을 써요. 그래서 아이디 찾기를 해도 "새 비밀번호 정하기" 링크가 함께 가요(무시해도 돼요).

## 알아둘 점
- Supabase 기본 메일 서버는 **시간당 발송 수가 아주 적어요**(개발용). 이용자가 늘면 Supabase → Project Settings → Authentication → **SMTP Settings** 에 메일 서비스(Resend 등)를 연결해야 해요. SMTP 비밀번호는 대시보드에만 입력하세요.
- **Redirect URLs** 에 사이트 주소가 등록돼 있어야 링크가 돌아와요(`http://localhost:5173/**`, 배포 후 배포 주소 — `docs/deploy_checklist.md` 참고).
- 메일이 안 오면 스팸함, 그다음 Supabase → Authentication → Logs 를 확인하세요.

## 시험 방법
1. 사이트 새로고침(Ctrl+F5) → 사람 아이콘 → **비밀번호 찾기** → 아이디·가입 이메일 입력 → 메일 확인.
2. 메일의 링크를 누르면 **새 비밀번호 정하기** 창이 열려요 → 두 칸에 같은 비밀번호 → **비밀번호 바꾸기**.
3. 로그아웃 후 새 비밀번호로 로그인.
