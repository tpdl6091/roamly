4. 다음 확인 사항

  • 실경험 인증을 위치·사진·영수증 중 무엇으로 할지 (개인정보·구현 난이도 비교 필요)
  • 취향 온보딩 질문 최종 문항과 동네 태그 체계
  • 6개 언어 UI에서 문구 길이 차이(독일어 등)에 따른 레이아웃 확인
  • 예산: 다중 통화 환산 방식(자동 환율 vs 수동 입력)과 환율 기준일 표시
  • 즉흥 추천: 위치·날씨 권한 거부 시 대체 흐름(수동 지역 선택)
  • 여행 기록: 사진 저장 용량·공개 범위(비공개 기본)와 "추천 작성" 전환 동선
  • 호스트: 신원 확인 방식(신분증·SNS·영상)과 국가별 유상 안내 규제 검토 전까지 프로그램은 무료·실비 분담으로 표기
  • 프로그램: 연락처 비공개 정책, 안전 안내 문구, 취소·노쇼 규칙
  • 식품: 제품 DB 확보 방법과 "구매 확인" 인증 방식, 국가별 반입 가능 여부 안내 책임 범위
